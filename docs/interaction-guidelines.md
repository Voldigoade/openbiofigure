# Interaction guidelines

The canonical interaction rules are maintained in the repository's [UX contract](https://github.com/Voldigoade/openbiofigure/blob/main/UX-CONTRACT.md). This page remains as a stable link for existing references.

OpenBioFigure prioritizes a tutorial-free create → arrange → save → export workflow, progressive disclosure, visible keyboard focus, local recovery, and clear licence/provenance status. Existing capability owners and behavior requirements are listed in the canonical contract.

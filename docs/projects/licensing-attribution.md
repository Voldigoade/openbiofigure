# Licensing and attribution

OpenBioFigure code is Apache-2.0. Scientific assets are separate works and retain their own licences. Placing an asset never relicenses it.

## What the project records

Catalog assets retain their provider, original source, creator when available, individual licence and licence URL, attribution requirement and text, modification state, and integrity checksum. The licensing panel lists the assets actually used by the figure.

Public-domain or CC0 items usually do not require credit, though provenance remains useful. CC BY items require attribution under their specific licence version. Never assume a neighbouring asset has the same terms.

## User imports

For a local SVG, enter only metadata you can support. Leave unknown values unknown rather than guessing. OpenBioFigure will preserve that uncertainty and report it before publication.

::: warning Not legal advice
OpenBioFigure helps track licensing metadata. You remain responsible for checking the applicable licence, publication policy, and intended use.
:::

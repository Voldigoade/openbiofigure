# Exporting

## SVG

Choose SVG when you need vector output, scalable geometry, or later editing in compatible software. OpenBioFigure embeds a machine-readable provenance summary without removing required visible or report-based attribution obligations.

## PNG

Choose PNG for slide decks, previews, and systems that require raster images. The export scale controls pixel dimensions: 2× is a practical default, while 3× or 4× creates larger files.

## Attribution report

Export the Markdown attribution report when the project contains scientific assets. It lists required credits and a complete provenance ledger. Keep it with the figure and adapt placement to the publication's requirements without deleting mandatory credit.

PDF export is not yet supported. Export SVG and use a trusted vector workflow when a journal requires PDF.

# Publication readiness

The publication check reviews the current figure and classifies findings as ready information, warnings, or blockers. It can identify empty content, generic titles, missing provenance, unknown licences, required attribution, modified attribution-sensitive assets, hidden objects, and unusually small text.

## Before export

1. Give the project a meaningful title.
2. Resolve missing or unknown asset metadata.
3. Review every required attribution and modification note.
4. Confirm hidden objects are intentionally excluded.
5. Check figure dimensions and raster export scale against the journal specification.
6. Save the editable project and export the attribution report.

The check improves metadata completeness; it does not assess scientific accuracy, journal compliance, accessibility of the scientific message, or legal compatibility.

# Saving projects

OpenBioFigure autosaves the active figure in local browser storage and shows its state in the editor. Autosave helps recover after a refresh, but it is tied to the current application profile and is not a portable backup.

Use **File → Save** to export an `.obf.json` project. This versioned JSON file contains the document, editable objects, embedded assets, provenance, and project settings. Store it with your research files and reopen it through **Open project**.

Do not rely on exported SVG or PNG as the only editable source. Browser data may be removed when site data or an application profile is cleared.

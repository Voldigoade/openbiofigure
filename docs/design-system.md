# Design system

The canonical OpenBioFigure visual system is maintained in the repository's [design specification](https://github.com/Voldigoade/openbiofigure/blob/main/DESIGN.md). Runtime tokens live in the [design-system stylesheet](https://github.com/Voldigoade/openbiofigure/blob/main/src/design-system.css).

The design direction is a modern scientific editorial workspace: calm application chrome around a dominant white figure document, locally bundled scientific typography, restrained teal provenance cues, and accessible semantic status colours.

The migration is intentionally staged. New and redesigned surfaces use semantic tokens; compatibility aliases keep validated editor workflows stable until each editor region receives focused visual QA.

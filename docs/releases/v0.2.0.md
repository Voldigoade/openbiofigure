# OpenBioFigure v0.2.0

OpenBioFigure v0.2.0 expands the local-first scientific figure editor with a substantially larger verified catalog and practical composition tools.

## Highlights

- 410 verified Bioicons assets, including 409 CC0-1.0 assets and one attribution-required CC-BY-3.0 asset
- Pinned, reproducible Bioicons ingestion with strict metadata, license, checksum, duplicate, Windows-path, and SVG-safety validation
- Ranked local search, filters, favorites, recent assets, and on-demand catalog loading
- Three editable scientific figure templates
- Editable cell, membrane, DNA, figure panel, scale bar, bar chart, and line chart groups
- Numeric sizing, keyboard nudging, grid and snap preferences
- Publication preflight and downloadable Markdown publication report
- Offline-capable web application and a Tauri Windows shell

## Release trust

Official static and Windows artifacts are built only by GitHub Actions on clean GitHub-hosted runners from the public tagged commit. The release includes SHA-256 checksums, an SPDX SBOM, build provenance, and GitHub artifact attestations. No Windows Authenticode signature is claimed.

See the [release verification guide](https://github.com/Voldigoade/openbiofigure/blob/main/docs/RELEASES.md) for verification commands.

## Known limitations

- Canvas manipulation remains primarily visual; accessible application-shell controls are stronger than direct canvas accessibility.
- Connectors are straight editable lines without semantic routing.
- Charts support straightforward non-negative bar and line datasets, not statistical analysis.
- Vector PDF and chemical structure authoring are not included.
- OpenBioFigure tracks licensing metadata but does not provide legal advice.

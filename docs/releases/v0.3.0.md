# OpenBioFigure v0.3.0

V0.3.0 makes OpenBioFigure easier to discover, learn, and use while preserving its local-first editor and provenance model.

## Product experience

- Introduces locally bundled IBM Plex and STIX typography, semantic light/dark themes, compact density, and reduced-motion support.
- Redesigns Home, New Figure, Settings, and the editor around clear beginner workflows and contextual controls.
- Adds a product homepage, dedicated web editor and download routes, and a self-hosted searchable documentation portal.
- Adds searchable Quick actions with `Ctrl/Cmd+K` for common creation, catalog, publication, and export tasks.

## Scientific creation

- Expands the original editable template library to six starting points: experimental workflow, comparison, microscopy, pathway mechanism, treatment timeline, and graphical abstract.
- Expands the verified Bioicons catalog to 733 assets: 409 CC0-1.0, 323 CC-BY-4.0, and one separately reviewed CC-BY-3.0 asset.
- Adds scientific topic browsing, deterministic synonym search, favorites, recents, provider filters, licence filters, and attribution indicators.
- Keeps SVG payloads separate from the initial editor JavaScript and loads previews and canvas assets on demand.

## Offline and release safety

- Keeps the searchable catalog available offline while limiting the web PWA shell precache to startup resources. Scientific SVGs use a separate bounded on-demand cache.
- Ships the full catalog inside the Windows application for offline insertion.
- Retains the real Windows Tauri smoke gate introduced in V0.2.1. The release workflow must render Home, enter New Figure, load a scientific asset, and expose its provenance before packaging.
- Official installers are built only by GitHub Actions from the tagged public commit and include checksums, an SPDX SBOM, build information, and artifact attestations.

OpenBioFigure does not provide legal advice or Windows Authenticode signing. See the [release verification guide](../RELEASES.md).

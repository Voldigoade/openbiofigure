# OpenBioFigure v0.1.0 release notes

This file prepares release notes; it does not claim that a Git tag or GitHub release exists.

## Highlights

- Compose scientific figures locally with core vector objects and sanitized scientific SVGs.
- Save versioned `.obf.json` projects and recover the latest autosave after refresh.
- Search a four-asset, individually verified Bioicons seed catalog.
- Carry source, creator, license, attribution, and modification metadata with placed assets.
- Run a publication check and export attribution as Markdown or text.
- Export editable SVG with embedded provenance metadata or PNG at 1×–4×.

## Scope and limitations

V0.1 is desktop-first, has a deliberately small seed catalog, and does not include vector PDF, semantic connector routing, collaboration, cloud sync, accounts, telemetry, or AI. User-supplied licensing metadata is not independently verified. OpenBioFigure does not provide legal advice.

# OpenBioFigure v0.2.1

V0.2.1 is a corrective desktop release. It does not introduce a new product redesign.

## Fixed

- Fixed a white-window failure that could affect the official V0.2.0 Windows application when an older PWA service worker remained attached to Tauri's persistent local origin. The stale HTML shell referenced removed hashed JavaScript and CSS files, so the WebView received HTML fallbacks where modules were expected and React never mounted.
- Added a versioned desktop startup URL that bypasses the stale root document, then unregisters desktop service workers and clears Cache Storage without deleting IndexedDB projects or local preferences.
- Added `'self'` to the desktop `connect-src` policy so the editor can fetch bundled scientific SVG files. General network origins remain disallowed.

## Release safety

- Added a real Windows smoke test using WebdriverIO, `@wdio/tauri-service`, and Tauri's test-only embedded WebDriver provider.
- The release-mode Tauri binary must render Home, open a new figure, enter the editor, load a bundled scientific asset, and expose complete provenance before packaging can begin.
- Windows installers are built only by the public GitHub Actions workflow on a clean `windows-latest` runner. Local binaries are not release inputs.
- Downloads include SHA-256 checksums, an SPDX SBOM, build information, and GitHub artifact attestations.

OpenBioFigure does not currently provide Windows Authenticode signing. See the [release verification guide](../RELEASES.md).

# Contributing

Contributions are welcome for focused bugs, features, documentation, code, scientific assets, and metadata corrections. Read the [Code of Conduct](https://github.com/Voldigoade/openbiofigure/blob/main/CODE_OF_CONDUCT.md) and the complete [contribution guide](https://github.com/Voldigoade/openbiofigure/blob/main/CONTRIBUTING.md).

Before opening a pull request:

1. Explain the user or scientific workflow being improved.
2. Keep the change focused and preserve local-first, vector-first behavior.
3. Add tests that would fail without the change.
4. Update format, security, or licensing documentation when contracts change.
5. Run `pnpm verify`.

Never include patient data, confidential research, credentials, personal information, uncertain-license assets, or locally built release binaries.

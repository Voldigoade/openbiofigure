# Scientific tools and charts

Built-in scientific elements create editable groups from ordinary project primitives. Available elements include a cell, phospholipid bilayer, DNA, figure panel, and scale bar. Their parts can be ungrouped and styled like other objects.

OpenBioFigure can also create straightforward bar and line charts from validated local data. Edit chart labels, colours, and dimensions after insertion. Charting is intended for figure composition, not statistical analysis; calculate and verify scientific results before importing them.

Panel and scale-bar tools help maintain consistent spacing and labels. Always confirm that a scale bar represents the actual image calibration.

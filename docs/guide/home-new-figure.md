# Home and new figures

Home keeps the highest-value actions first: create a figure, open a project, continue local work, or choose a template.

## New figure

The dialog has two starting modes. **Blank figure** offers square, 16:9, A4 portrait, A4 landscape, journal, and custom pixel dimensions. **Use a template** creates an editable composition rather than a flattened image.

![The New figure dialog showing blank presets and template choices](/screenshots/new-figure.png)

Settings can change the default blank preset and whether OpenBioFigure starts at Home or reopens the current autosave. Recent projects are local history entries, not cloud files.

## Open project

Choose an `.obf.json` file created by OpenBioFigure. Invalid, damaged, or unsupported files are rejected without replacing the active figure.

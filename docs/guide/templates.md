# Templates

Templates provide structure while keeping every object editable. OpenBioFigure currently includes:

- **Experimental workflow:** four steps and directional flow.
- **Comparison A/B:** two labelled regions for groups or conditions.
- **Microscopy grid:** four labelled image regions with scale bars.

Choose a template from Home or from the **New figure** dialog. Rename labels, replace placeholders, change colours, resize panels, and add scientific assets as normal. Templates do not add hidden licensing claims; any catalog asset you place still carries its own metadata.

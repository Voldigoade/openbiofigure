# Editor basics

The editor uses four predictable regions: menus and tools at the top, scientific assets on the left, the canvas in the centre, contextual properties and layers on the right, and status information at the bottom.

![OpenBioFigure editor with an editable experimental workflow](/screenshots/editor.png)

## Select and arrange

Click an object to select it. Shift-click to build a multi-selection. Drag handles to resize or rotate, and use alignment or distribution commands for precise groups. Copy, paste, duplicate, group, ungroup, lock, hide, reorder, undo, and redo are available through familiar menus and keyboard shortcuts.

## Navigate the canvas

Use zoom controls or **Fit to screen**. Pan mode moves the viewport rather than figure objects. The grid is optional; snapping follows the project setting.

## Contextual properties

The right panel changes with the selection. Compatible objects expose fill, stroke, width, opacity, typography, alignment, position, and dimensions. Advanced controls stay out of view until they are relevant.

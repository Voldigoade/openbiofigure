# Layers

Layers list figure objects from front to back. Use the panel to select overlapping items, rename objects, change visibility, lock editing, and adjust stacking order.

- **Visibility** removes an object from the canvas and exports without deleting it.
- **Lock** prevents accidental canvas manipulation while preserving the object.
- **Bring forward/backward** moves one level.
- **Bring to front/back** moves to the extreme of the stack.

Hidden or locked objects remain part of the project. The publication check reports hidden content so it is not overlooked before export.

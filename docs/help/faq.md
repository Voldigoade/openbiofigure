# Frequently asked questions

## Do I need an account?

No. Core editing, bundled asset search, save, and export are local.

## Does OpenBioFigure upload my research?

No telemetry or project upload is built in. External links use your browser and network only when you open them.

## Is every scientific asset Apache-2.0?

No. Apache-2.0 covers the software. Each scientific asset retains its own recorded licence.

## Can I use my own SVG?

Yes. It is sanitized on import. Add provenance when known; no licence is inferred.

## Does OpenBioFigure replace scientific review?

No. It assists composition and metadata tracking, not scientific, journal, accessibility, or legal review.

## Why is PDF absent?

The current release prioritizes editable SVG and reliable PNG. Vector PDF remains planned rather than being shipped with uncertain fidelity.

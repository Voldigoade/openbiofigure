# Your first figure

This workflow creates a small, editable figure and keeps a portable project copy.

## 1. Start from Home

Open OpenBioFigure and choose **New figure**. Select a template when its structure matches your story, or choose a blank preset for full control. **Experimental workflow** is a useful first template because every step and connector is editable.

![OpenBioFigure Home with New figure, Open project, and editable templates](/screenshots/home.png)

## 2. Add a scientific asset

Use the search field in the left panel and enter `cell`. Choose a result, inspect its provider and licence when needed, then click it or drag it onto the canvas. The asset's provenance travels with the project.

## 3. Explain the relationship

Choose **Text** to add a concise label. Add an **Arrow** or **Connector**, then drag, resize, or rotate the objects. Use the Layers panel to select an object that is difficult to reach on the canvas.

## 4. Save a portable project

Autosave protects the active browser profile, but it is not a portable backup. Use **File → Save** to download an `.obf.json` project. Reopen it later with **Open project**.

## 5. Check and export

Open **Attribution / Licensing** and review the publication check. Resolve unknown provenance and required modification notes. Export SVG for an editable vector result or PNG for a raster image. Export the attribution report when the figure uses credited assets.

::: tip A useful first habit
Save the project file before exporting the final figure. SVG and PNG are outputs; the `.obf.json` file is the complete editable source.
:::

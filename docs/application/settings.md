# Settings

Settings are stored on the current device and apply immediately.

![OpenBioFigure Settings with section navigation and local preferences](/screenshots/settings.png)

- **General:** startup destination and number of recent projects shown.
- **Appearance:** light, dark, or system theme and comfortable or compact density.
- **Editor:** default grid size and snap-to-grid behavior.
- **Documents:** default blank-document preset.
- **Export:** default PNG scale; SVG remains vector-first.
- **Files:** local autosave explanation and recent-list clearing.
- **Accessibility:** reduced interface motion.
- **Privacy:** the current local-first and network behavior.
- **About:** version, source, releases, issue reporting, security, and third-party font licences.

Clearing the recent list removes history entries; it does not delete exported project files.

## Choose where to begin

- **New to OpenBioFigure?** Follow [Your first figure](/getting-started/first-figure).
- **Ready to install?** Compare the [web and Windows versions](/getting-started/installation).
- **Preparing a manuscript?** Run the [publication readiness check](/projects/publication-readiness).
- **Contributing code or assets?** Start with the [developer documentation](/developers/).

::: info Local-first by default
OpenBioFigure does not require an account and does not send telemetry. Projects remain on your device unless you explicitly export or share them.
:::
